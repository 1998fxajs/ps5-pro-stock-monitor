# PS5 Pro Stock & Deal Monitor

국내 PS5 Pro 2TB **신품 본체 단품** 판매·입고·프로모션을 찾아 텔레그램으로 알리는 무료 GitHub Actions 프로젝트입니다. 게임 개발 저장소와 독립적으로 운영합니다.

## 가격 및 구매 정책

- 단품 정가 우선: **1,298,000원 이하**에서 재고 확인 알림.
- 최대 1,380,000원 상품 및 추첨·프로모션은 **정보 확인용 알림**으로만 취급.
- 추가 컨트롤러·디스크 드라이브 번들, 중고, 리퍼, 해외직구, 울버린 세트는 자동 구매 대상에서 제외.
- **구매·로그인·결제 자동화 없음.** 기존 매크로의 실제 소스는 확보하지 못했습니다. 자동 구매 1대 제한은 도입 시 별도 검증 필요.
- 가격이나 재고가 불확실한 사이트를 구매 가능하다고 확정하지 않습니다.

## 감시 기간

**2026년 11월 15일 ~ 11월 19일 23:59:59 (한국시간).** 11월 20일 00:00 KST부터 모든 감시 코드가 외부 요청/알림 전송을 중단하며, 각 워크플로는 다음 실행 시 GitHub Actions 예약 실행 자체의 비활성화를 시도합니다. GitHub의 자동 비활성화 권한이 부족해도 스크립트 차원의 종료 조건은 적용됩니다.

## 신규 상품 페이지와 갑작스러운 판매

직접 상품 재고 검사만으로는 새 상품번호·새 판매 페이지를 발견할 수 없어, 프로모션 감시 안에 `catalog_watch.py`를 추가했습니다.

- **겜우리**: Pro 공식 카테고리
- **겟디즈**: 공개 전체 상품 목록 및 연결된 플레이스테이션 카테고리
- **SSG/이마트**: 공개 상품 검색 결과 (GitHub 환경에서는 HTTP 403 발생하여 현재 해당 경로 감시 불가)
- **컴퓨존**: 공개 상품 검색 (현재 제목·상품번호를 확정하지 못함)
- **G마켓**: 기존 합의대로 직접 요청 없이 공개 판매글·커뮤니티·특가 정보만 검색

새 상품 URL은 첫 성공 실행에서 기준 목록을 만든 뒤, 이후 새로운 링크가 발견되면 텔레그램에 **판매 페이지 발견 — 가격·재고 확인 필요**로 전송합니다. Google 뉴스와 커뮤니티 공지의 업데이트는 별도 탐색하며, 발견한 동일 실행에서 알림을 보냅니다. 이는 30초 이내 도착이나 검색 결과의 실시간 색인까지 보장하지는 않습니다.

## 5분 내부 반복 감시 (2026-11-16 적용)

기존 GitHub Actions `*/5` 예약 작업이 실제로는 약 1시간 이상 늦어지는 문제가 확인되어 방식을 변경했습니다.

- **판매처 감시**: 매시 13분경 새 실행 요청(UTC) + 실행 중인 GitHub runner에서 `watch_loop.py retail`을 약 **5분마다** 반복. 새 실행은 최대 140분간 동작 후 종료하며, 동일 그룹의 예약 대기 실행과 교대합니다.
- **판매글·특가·새 상품·디시 감시**: 매시 17분경 새 실행 요청(UTC) + `watch_loop.py promo`에서 세 검사기를 **약 5분마다** 실행.
- 중복 실행을 피하기 위해 같은 그룹은 한 번에 하나의 runner만 실행합니다.
- 2026년 11월 19일 23:59:59 KST 이후 모든 검사·텔레그램 발송은 중단됩니다.
- **중요:** 한 번 시작된 runner 안에서는 5분 간격을 목표로 하지만, GitHub 예약 실행 자체가 지연·누락되거나 runner가 중단되면 감시에 공백이 생길 수 있습니다. 끊김 없는 24시간 5분 간격이나 30초 이내 알림은 보장하지 않습니다.
- GitHub 공개 저장소의 표준 runner는 무료로 제공되지만 GitHub 사용 제한·정책과 판매처의 요청 제한을 준수해야 합니다.

## 작동하는 워크플로

1. **[판매처 감시](https://github.com/1998fxajs/ps5-pro-stock-monitor/actions/workflows/retail-watch.yml)**: 겜우리, 이마트몰/SSG, 컴퓨존, 겟디즈의 공개 단품 상품 페이지를 약 5분 주기로 조회. GitHub Actions 실행시각은 지연되거나 누락될 수 있습니다.
2. **[판매글·특가·추첨 발견](https://github.com/1998fxajs/ps5-pro-stock-monitor/actions/workflows/promo-watch.yml)**: Google 뉴스 RSS에서 PS5 Pro, PS5프로, 플레이스테이션5 프로, 플스5프로, CFI-7122B 및 G마켓 전용 검색을 포함한 11개 검색 그룹을 확인하고, 같은 워크플로에서 새 상품 페이지 링크도 검사합니다. 뽐뿌 공개 RSS 두 곳도 별도로 시도합니다.
3. **디시인사이드**: Google 뉴스에 디시인사이드 전용 검색어를 추가했고, 공개된 **핫딜·할인상품·PlayStation 갤러리 첫 페이지**의 새 게시글도 직접 확인합니다 (`dcinside_watch.py`). 직접 조회가 막히면 로그에 기록하며, 게시글은 재고·정가 검증 전의 참고 알림입니다.
4. **[텔레그램 메시지 테스트](https://github.com/1998fxajs/ps5-pro-stock-monitor/actions/workflows/test-telegram.yml)**: 수동 테스트. 사용자 휴대폰 수신 확인 완료.

모든 알림은 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` GitHub Actions Secrets를 통해 전송합니다. 자격정보를 코드에 업로드하지 마세요.

플레이샵 직접 상품 감시 워크플로는 요청에 따라 삭제했습니다. **G마켓은 요청에 따라 직접 조회를 완전히 제외했습니다.** GitHub 실행환경에서 HTTP 403이 확인됐으며, G마켓 이름이 포함된 공개 판매 공지·핫딜·커뮤니티 게시글을 발견하면 텔레그램 알림을 보내는 방식만 사용합니다. 이는 실제 재고 확인이 아니며 검색 색인 반영이 늦거나 누락될 수 있습니다.

## SSG 감시의 실측 한계 (2026-11-15)

- 기존 이마트몰 상세주소는 HTTP 200을 반환하지만 응답은 상품명이나 판매상태가 없는 약 1.9KB 페이지여서 유효한 재고 정보가 아닙니다.
- SSG 통합몰/모바일몰/신세계몰 상품 링크는 GitHub 실행환경에서 403을 반환합니다.
- 이마트몰의 공개 검색·카테고리도 검증된 신규 상품 링크를 추출하지 못했습니다.
- **SSG 새 상품 목록 직접 조회는 현재 GitHub 실행환경에서 접근 거부 또는 불완전한 콘텐츠 때문에 작동하지 않습니다.** 직접 재고 감시를 정상이라 표시해서는 안 됩니다.
- 대체 감시로 SSG·이마트·쓱라이브 관련 공개 판매글/커뮤니티 검색이 켜져 있지만 이 방식은 신규 상품 등록 즉시 알림을 보장하지 않습니다.
- CAPTCHA, 로그인, 봇 차단을 무력화하는 우회는 적용하지 않았습니다.

## 알림 정확도

- 정형 상품 데이터에서 명확히 `InStock`이 확인되고 품명·정가·통화가 조건에 맞으면 **재고 감지** 알림.
- 기존 품절 표시가 사라졌다면 **확인 필요** 알림. 이것은 실제 재고 보장이 아닙니다.
- 직접 감시 대상 4곳에서 접근 오류가 발생하면 **감시 장애**로 구분해 상태 변경 시 알림. G마켓은 직접 조회하지 않으므로 장애 알림도 보내지 않음.
- RSS에 새 상품 판매 공지가 나오면 **판매 정보 확인 필요** 알림. 제목에 PS5 Pro가 있어도 실제 판매 여부를 보장하지 않습니다.
- 검색 색인 지연, 실행 대기, 판매처 제한, 페이지 구조 변경이 존재하므로 **실시간·30초 이내 도착·전체 매물 감지를 보장하지 않습니다.**

테스트: `python3 -m unittest test_retail_watch.py test_promo_watch.py -v`.

GitHub 상태 기록: `retail_state.json` / `promo_seen.json`. 불명 상태의 판매처는 계속 검증이 필요합니다.
