# PS5 Pro stock and community lead monitor

국내 PS5 Pro 구매 기회를 공개 판매처·커뮤니티·검색에서 발견해 기존 텔레그램으로 알리는 무료 GitHub Actions 감시입니다. 로그인, 구매, 결제, CAPTCHA/차단 우회를 수행하지 않습니다.

## 현재 알림 기준 — 2026-11-17 사용자 정정 반영

구매 가능성을 알리는 관련 글을 발견하면 본문과 연결된 링크를 읽고 **확인 필요 제보**로 보냅니다. 제목에 정확한 PS5 Pro와 정형 판매 문구가 동시에 있어야 한다는 조건을 제거했습니다. 희망 가격 초과나 번들 구성은 알림에 표시하며, 커뮤니티 제보를 조용히 버리는 사유로 사용하지 않습니다. 구매 자동화는 없습니다.

- 디시 ps5, playstation은 새 글을 제목 조건 없이 본문 검토합니다. 핫딜·할인상품 갤러리도 유지합니다.
- 실제 열람한 글 23건을 observed_community_posts.json에 등록했습니다. community_language.json의 표현에는 확인한 글의 출처가 있습니다. 사전식 단어 목록을 완전한 언어 이해라고 주장하지 않습니다.
- 상품명이 생략된 구매·취소분 제보, 판매처 이름만 있는 글, 링크만 있는 본문과 사진을 포함한 제보를 처리합니다.
- 제목은 후보 발견에 사용하며, 실제 게시글 영역과 연결 상품의 제목을 읽어 본체 포함 여부를 판단합니다. 사이트 메뉴·광고·관련 글은 본문에서 분리합니다. 본체 단품이 우선이지만 본체가 포함된 판매 구성을 액세서리 이름만 보고 제외하지 않습니다. 본체 없는 게임·구독·주변기기 상품은 제외합니다.
- 본문 사진은 무료 Tesseract 한국어/영어 OCR로 읽습니다. OCR은 오인식하거나 실패할 수 있으며, 판독 상태를 알림과 로그에 표시합니다. 사진이 있다는 사실만으로 본체 증거를 만들지 않습니다. 본문 접근 실패와 미판독 후보는 완료 처리하지 않고 재시도합니다.
- HTML에 없는 동적 댓글, 이미지 속에만 적힌 URL, 로그인 전용 내용은 읽지 못합니다. 접근 실패를 재고 없음으로 바꾸지 않습니다.

## 발견 경로

1. 판매처 직접 조회: 겜우리, SSG/이마트, 컴퓨존, 겟디즈, 실제 제보에서 추출한 쿠팡 상품. 쿠팡은 이번 로컬 점검에서 HTTP 403이므로 직접 재고 확인은 불가합니다.
2. 디시: ps5, playstation, hotdeal1, discountproduct. 댓글 수 앵커가 제목을 덮어쓰던 오류를 수정했고, 새 글이 첫 페이지를 벗어날 때 최대 3페이지까지 확인합니다.
3. Google 뉴스 RSS와 뽐뿌 RSS. 뉴스 외에 **일반 Bing 웹 검색 RSS 6개와 핫딜모음 검색 3개**를 독립적으로 추가했습니다. source_registry.json에 실제 감시 URL을 등록했습니다.
4. 기존 새 상품 목록 검사와 플레이샵 공식 응모 일정 감시를 유지합니다. 기존 요청에 따른 G마켓/플레이샵 직접 재고 조회 제외도 유지합니다.

외부 검색은 색인 지연이나 누락이 있습니다. 등록한 경로가 인터넷의 모든 글을 포함한다는 의미는 아닙니다. 소스별 결과 개수와 실패를 로그에 남깁니다.

검색 결과는 실제 게시시각을 확인할 수 있고 3시간 이내일 때만 알림으로 보냅니다. 발견 시각을 게시시각으로 대체하지 않습니다. 날짜가 없는 홈페이지·오래된 검색 결과는 발송하지 않습니다. 본문 판정은 규칙과 OCR을 사용하는 제한적인 자동 판정이며 사람 수준의 언어 이해나 무오류를 보장하지 않습니다.

`MONITOR_DRY_RUN=1` 검증은 메시지와 감시 완료 상태를 모두 저장하지 않습니다. `validate_context_live.py`는 현재 공개 본문과 과거 사진을 읽어 `context-validation.json`에 기록하는 읽기 전용 검증입니다. 실제 테스트 알림은 보내지 않습니다.
